# Frozen analysis release contents

This directory is meant to be published as one versioned snapshot. The owner and public repository URL are verified; the v1.0.0 Release URL and commit SHA are pending. No DOI is requested.

- Scientific input: `data/Source_*` and `data/Analysis_Input_16Conditions.csv` (summary-table values only)
- Fixed numerical parameters: `config/Variable_ID_Registry.csv` and `config/Calculation_Constants.csv`
- Executable reproducibility: `run_all.py`, `code/`, `requirements.txt`
- Independent smoke tests: `tests/test_reviewer_smoke.py`
- Numerical results and check reports: `results/`
- Code and data scope/readme: `README.md`, `INSTALL_AND_RUN.md`
- GitHub URL/tag/commit instructions: `GITHUB_RELEASE_CHECKLIST.md`

A companion **Word** explanation of equations and code traceability is prepared separately and is not redistributed in this repository. Instrument raw signals and manuscript source DOCX files are not included.
